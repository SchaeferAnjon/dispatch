# DESIGN.md template (in the project root, committed to the repository)

Write concrete values and variable names, not adjectives. At most 10 lines per section.

```markdown
# <project> interface standard

One sentence on its place: who it is for, which products it resembles (for example: one material and two greys, like Raycast).
The tokens are in <file path>.

## Type
Font stack, sizes (use → px/line height/weight), the heaviest weight, letter-spacing, text-autospace, the fixed-width allow-list.

## Colour (variable names only)
Surfaces / text / lines / fills / the one solid button / which state each semantic colour means / where identity colours appear.
The rule that default states show no label.

## Sizes
Spacing steps, radius steps (variable → px → use), line height, header and footer, icon specification.

## Components
List row structure, group headings, tags and key caps, empty states, the input box and its status line, the navigation bar, the detail pane: one line each with sizes and the tokens used.

## The person's preferences
A list of likes / dislikes (from `dispatch prefs list --area design` or the conversation).

## References
Links to outside guidelines.
```
