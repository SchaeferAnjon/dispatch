## 这一版

- **交接和交付又存得进了**：一个项目攒了很多交付和交接以后，`dispatch handoff write` 和 `dispatch task deliver` 会报 `Error 1105 … too large for column 'value'`，什么都存不进。原因是这个项目的 Docs 登记表整份放在任务板的一格里，那一格最多 65,535 字节。现在存之前先把登记表裁到 60,000 字节以内：先去掉文件已经不在的删除记号，再去掉最旧的交接（它们在任务评论和 `dispatch handoff show` 里还看得到），再去掉最旧的其他文档，刚登记的那条一定留着。别的内容再超出上限时，报错会说清是哪一格、有多大、上限多少，不再把几十 KB 的原文打到屏幕上。
- **新会话页也能录屏口述**：新会话页的输入框里，发送键左边也有 Point and talk 的摄像机按钮，⌃⇧S 在这一页按下就录进这个输入框。录制中、停下后和权限卡都和会话里的一样。
- **点任务就地展开**：右栏 Now 里点任务标题，和点箭头一样在原地展开、收起步骤，不再跳到 Tasks 页签。对话里指向本会话任务的链接会切到 Now、展开那一行并闪一下。
- **子 Agent 用 VS Code 原版的样子**：左栏父会话下面、输入框上方和右栏 Now 三处都显示 VS Code 原版的子 Agent 胶囊，点开是对话旁边的只读页签。子 Agent 一直挂在父会话下面；跑完的收进「N finished」，可以点 × 清掉。后台子 Agent 结束时，父对话正好空闲也能收到结束信号，不再一直显示在跑。
- **右栏 Changes 回到 VS Code 原样**：去掉了按轮次筛选的胶囊、谁写的行的标记和每块改动的 Why / More；选中文字后的 Quote 和 Ask Question 还在。你改了几行仍显示在回复下面和提交卡上。
- **终端命令**：`dispatch ide instance` 起的测试实例窗口不再冒到屏幕上（隐藏窗口的脚本在某些情况下报 `list index out of range`，已修好）。

**更新**：装着 0.9.5 到 0.9.8 的 Mac 会自己查到这一版，下载好后底栏出现重启更新。没装过的，下载 dmg，第一次打开照上面「安装」里的步骤放行一次。

**要求**：macOS 14 或更新，Apple 芯片（M 系列）；你自己的 Claude Code 或 Codex 订阅，或者 OpenCode。不需要 Homebrew。

**许可**：GPL-3.0。

## This release

- **Handoffs and deliveries save again**: once a project had collected many deliveries and handoffs, `dispatch handoff write` and `dispatch task deliver` failed with `Error 1105 … too large for column 'value'` and saved nothing. The project's Docs list was stored whole in one cell of the task board, which holds at most 65,535 bytes. The list is now trimmed below 60,000 bytes before it is saved: first the markers for files that no longer exist, then the oldest handoffs (they stay in the task comments and in `dispatch handoff show`), then the oldest other documents; the entry just added is always kept. When something else is too large, the error names the cell, its size and the limit instead of printing tens of kilobytes of the value.
- **Point and talk on the new session page**: the new session page's message box has the Point and talk camera to the left of Send as well, and ⌃⇧S on that page records into that box. Recording, the box after you stop, and the permission cards work as they do in a session.
- **Tasks open in place**: clicking a task's title in Now opens and closes its steps in place, like the arrow, instead of switching to the Tasks tab. A link in the conversation to one of this session's tasks switches to Now, opens that row and flashes it once.
- **Sub-agents look like VS Code's own**: under the parent session in the sidebar, above the message box and in Now, sub-agents show as VS Code's own sub-agent pills; clicking one opens a read-only tab beside the conversation. Sub-agents always stay under their parent session; finished ones fold into N finished, and × clears them. A background sub-agent that ends while the parent conversation is idle is now marked as ended instead of looking like it still runs.
- **Changes is back to the VS Code original**: the per-turn filter pills, the who-wrote-this-line marks and the Why / More on each change are gone; Quote and Ask Question on selected text stay. How many lines you changed still shows under the reply and on the commit card.
- **Command line**: test windows started by `dispatch ide instance` no longer appear on your screen (the script that hides them sometimes failed with `list index out of range`; fixed).

**Updating**: a Mac with 0.9.5 to 0.9.8 finds this version by itself; once it has downloaded, Restart to Update appears in the status bar. For a new install, download the dmg and allow it once on first open, as described under Install above.

**Requirements**: macOS 14 or later on Apple silicon (M series); your own Claude Code or Codex subscription, or OpenCode. Homebrew is not needed.
