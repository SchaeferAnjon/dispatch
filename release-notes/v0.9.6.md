## 这一版

- **Point and talk 边指边说**：输入框发送键左边的摄像机，或在任何 App 里按 Shift+Ctrl+S，录鼠标所在那块屏和你的声音，不用先选软件。边说边出字，指针停住的地方记成带红框的画面；停下后在输入框里删画面、改字，一条消息发给 Agent。识别用 Soniox，读你自己在 `dispatch env` 里存的 `SONIOX_API_KEY`。第一次用 macOS 会要屏幕录制和麦克风授权，屏幕录制授权后要重开一次 Dispatch。
- **Side chat 放到 Now 下面**：右栏上下两格，上面是 Now 或别的页签，下面是 Side chat，中间一条线拖着调高低，双击回默认，点格头收起。Side chat 里你问的那句话滚走后收成顶上一行，点它跳回。
- **方圆角**：按钮、卡片、输入框、你的消息气泡都换成 VS Code 那种小圆角。
- **思考档位菜单**：菜单里只放档位；你选过的档标「Last picked」，和「Default」那档并排，看得出为什么勾在这。
- **新官网**：https://dispatch.us-cloud.uk/ ，也加进了 https://apps.us-cloud.uk/ 。

**更新**：装着 0.9.5 的 Mac 会自己查到这一版，下载好后底栏出现重启更新。没装过的，下载 dmg，第一次打开照上面「安装」里的步骤放行一次。

**要求**：macOS 14 或更新，Apple 芯片（M 系列）；你自己的 Claude Code 或 Codex 订阅，或者 OpenCode。不需要 Homebrew：任务板用的 bd 和 Dolt 已经打在 App 里（0.9.5 的说明这里写错了）。

**许可**：GPL-3.0。

## This release

- **Point and talk**: the camera next to Send, or Shift+Ctrl+S in any app, records the screen under your pointer and your voice, with no app to pick. Your words appear as you speak, and the spots where your pointer rests become pictures with a red box; after you stop, delete pictures or fix words in the input box and send it all to the agent as one message. Speech recognition is Soniox, using the `SONIOX_API_KEY` you keep in `dispatch env`. The first time, macOS asks for screen recording and microphone access; after granting screen recording, reopen Dispatch once.
- **Side chat under Now**: the right panel has two parts, the current tab (Now or another) on top and Side chat below. Drag the line between them, double-click it to reset, click the header to fold it. In Side chat, your question shrinks to one line at the top when it scrolls away; click it to jump back.
- **Square corners**: buttons, cards, the input box and your message bubbles use the same small corners as VS Code.
- **Thinking level menu**: the menu lists only the levels; a level you picked before is marked Last picked next to the Default one, so you can see why it is ticked.
- **New website**: https://dispatch.us-cloud.uk/, also listed on https://apps.us-cloud.uk/.

**Updating**: a Mac with 0.9.5 finds this version by itself; when it is downloaded, a restart button appears in the status bar. For a new install, download the dmg and allow it once on first open, as described under Install above.

**Requirements**: macOS 14 or later on Apple silicon (M series); your own Claude Code or Codex subscription, or OpenCode. Homebrew is not needed: bd and Dolt for the task board come inside the app (the 0.9.5 notes got this wrong).

**License**: GPL-3.0.
