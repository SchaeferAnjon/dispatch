## 这一版

这是 Dispatch 的第一个公开版。源码按 GPL-3.0 开放在这个仓库，安装包有 Developer ID 签名、经过 Apple 公证，下载后双击就能打开。

Dispatch 是给 Claude Code、Codex、OpenCode 这些官方命令行 Agent 套的桌面界面：左边看所有会话，中间聊天，右栏看 Agent 正在干什么、每一轮改了哪些文件、为什么这么改。它不自己调模型，用的是你自己的订阅。

这几天做完的：

- **状态记号统一成 VS Code 那套**：做完是实心圆勾，正在做是实心绿圆，还没做是空心圈，整个软件只用这一套。
- **子 Agent 条**：主 Agent 派出子 Agent 时，输入框上方出一块，看得见每个子 Agent 叫什么、在做哪一步、跑了多久；点一行打开它自己的对话。
- **旁聊卡**：选中一段文字点 Ask Question，问题放进右下角一张浮着的卡，原来的对话不被打断；问完可以把答案加回对话，或在那段话下面留一条批注。
- **边干边学**：
  - 随身老师：编辑器里的代码、Changes 里的改动、终端输出、回复里的字，选中都能问。
  - 小卡：Agent 新建文件、装包、删文件时，右下角冒一张小卡说一句它在做什么；Settings 里可以在 Quiet 和 Talk 之间切换。
  - 带我看一遍：一轮做完，点 Walk me through，按文件一站一站看这一轮改了什么。
  - Why / More：Changes 里每块改动都能问为什么这么改，或者把那几行拿去接着问。
- **任务链接在右栏打开**：回复里的任务链接一点，右栏 Tasks 就地展开这件任务，对话不动。
- **钉住那一行**：往下滚时，你问的那句话收成顶上一行细字，点一下滚回去。
- **方案三落块**：会话在跑时的小图标改回方块从高处落下、越落越快的那一版。

**要求**：macOS 14 或更新，Apple 芯片（M 系列）的 Mac；你自己的 Claude Code 或 Codex 订阅，或者 OpenCode（可以接各家模型）。首次设置会用 Homebrew 装 Dolt 等依赖。

**许可**：GPL-3.0。

## This release

This is the first public release of Dispatch. The source is open in this repository under GPL-3.0, and the app is signed with a Developer ID and notarized by Apple, so it opens with a double-click after download.

Dispatch is a desktop app around the official command-line agents, Claude Code, Codex and OpenCode: all your sessions on the left, the chat in the middle, and on the right what the agent is doing right now, which files each turn changed and why. It never calls a model itself; it uses your own subscriptions.

Finished in the last few days:

- **One set of status marks, the VS Code one**: done is a filled check circle, working is a filled green circle, not started is an empty circle, everywhere in the app.
- **Subagent strip**: when the main agent starts subagents, a block above the input box shows each one's name, its current step and how long it has run; click a row to open its own conversation.
- **Side chat card**: select some text and click Ask Question; the question goes into a floating card at the bottom right and the main conversation is not interrupted. Afterwards you can add the answer to the chat or keep it as a comment under that passage.
- **Learn while it works**:
  - A tutor at hand: select code in the editor, a change in Changes, terminal output or text in a reply, and ask about it.
  - Small cards: when the agent creates a file, installs a package or deletes something, a small card at the bottom right says what it is doing in one sentence. Switch between Quiet and Talk in Settings.
  - Walk me through: when a turn is done, click Walk me through to step through that turn's changes file by file.
  - Why / More: every change in Changes can tell you why it was made, or hand those lines on for a follow-up question.
- **Task links open in the right panel**: click a task link in a reply and the task opens in place under Tasks on the right; the conversation stays where it is.
- **Pinned line**: when you scroll down, your question shrinks to one thin line at the top; click it to scroll back.
- **Falling blocks, version three**: the small icon of a running session is back to blocks that fall from above and speed up as they drop.

**Requirements**: macOS 14 or later on a Mac with Apple silicon (M series); your own Claude Code or Codex subscription, or OpenCode (which works with many model providers). First-run setup installs Dolt and a few other tools with Homebrew.
