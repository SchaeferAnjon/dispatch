## 这一版

- **录屏时一眼看出在录**：Point and talk 录制时，输入框底行最左边是呼吸的红点、「Recording」和计时，原来的灰色摄像机不再出现。Dispatch 不在被录的屏上时，屏幕顶上那条浮条里也换成红点。
- **被录的屏四边一圈流动红框**：从开始录到停下，被录那块屏的四条边一直有一圈流动的红框，切到别的软件也看得见；它不录进视频，也不挡鼠标。
- **停下后的输入框**：转写区四周不再多套一层灰框，只剩输入框自己的边。转写很长时最多 168px 高，多了在框里滚动，不再把对话挤成一条缝。
- **一轮回复收起后看得见回答**：Agent 一轮做完收成「Completed N steps」时，只收工具步骤和思考，这轮写给你的文字按原来的顺序留在外面，不再只露最后一句。点那一行照样展开、收起全部步骤。
- **终端命令**：`dispatch ide instance` 起测试实例时窗口不再冒到屏幕上（CLI 包里补上了漏掉的脚本）。
- **What's new**：第一条换成「Recording you can see」，配录制中的截图，点 Show me 指到输入框的摄像机。

**更新**：装着 0.9.5、0.9.6 或 0.9.7 的 Mac 会自己查到这一版，下载好后底栏出现重启更新。没装过的，下载 dmg，第一次打开照上面「安装」里的步骤放行一次。

**要求**：macOS 14 或更新，Apple 芯片（M 系列）；你自己的 Claude Code 或 Codex 订阅，或者 OpenCode。不需要 Homebrew。

**许可**：GPL-3.0。

## This release

- **You can see that it's recording**: while Point and talk records, the left end of the message box's bottom row shows a pulsing red dot, Recording and the time; the grey camera is gone. When Dispatch is not on the recorded screen, the bar at the top of the screen shows the red dot too.
- **A moving red line around the recorded screen**: from start to stop, a red line runs around the four edges of the screen being recorded. You see it in other apps as well; it is not in the video and does not get in the way of the pointer.
- **The message box after you stop**: the transcript no longer has an extra grey frame inside the box. A long transcript is at most 168 px tall and scrolls inside the box instead of squeezing the conversation.
- **Folded replies keep the answer**: when a finished turn folds into Completed N steps, only the tool steps and thinking fold; the text written to you stays outside, in its original order, instead of only the last sentence. Clicking the row still opens and closes all the steps.
- **Command line**: `dispatch ide instance` no longer puts test windows on your screen (a script missing from the CLI package is now included).
- **What's new**: Recording you can see is now first, with a picture of a recording in progress; Show me points at the camera in the message box.

**Updating**: a Mac with 0.9.5, 0.9.6 or 0.9.7 finds this version by itself; once it has downloaded, Restart to Update appears in the status bar. For a new install, download the dmg and allow it once on first open, as described under Install above.

**Requirements**: macOS 14 or later on Apple silicon (M series); your own Claude Code or Codex subscription, or OpenCode. Homebrew is not needed.

**License**: GPL-3.0.
