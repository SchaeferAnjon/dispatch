## 这一版

- **加 Soniox Key 更顺手**：Point and talk 提示要 Key 时，点 Open Keys 直接打开填好名字 `SONIOX_API_KEY` 的表单，光标在值上，粘贴保存，卡片自己消失，再点摄像机就能录。
- **Settings › Keys 的 Add key 挪到最上面**：和搜索框同一行，Key 再多也不用滚到底才能加；Key 已存在时打开它的编辑。
- **选中文字引用条**：在 Side chat 里回车发出后，引用条自己收起，不再留在原处。
- **更新提示**：「In this update」里的四样新东西配上了截图，点开能看到在哪。

**更新**：装着 0.9.5 或 0.9.6 的 Mac 会自己查到这一版。没装过的，下载 dmg，第一次打开照上面「安装」里的步骤放行一次。

**要求**：macOS 14 或更新，Apple 芯片（M 系列）；你自己的 Claude Code 或 Codex 订阅，或者 OpenCode。不需要 Homebrew。

**许可**：GPL-3.0。

## This release

- **Adding the Soniox key**: when Point and talk asks for a key, Open Keys opens the form with the name `SONIOX_API_KEY` filled in and the cursor in the value. Paste, save, and the card goes away; press the camera again to record.
- **Add key at the top of Settings › Keys**: it sits next to the search box, so you no longer scroll to the end of a long list to add one; for a key that exists already it opens its Edit.
- **Quote bar**: after you send from Side chat, the quote bar of the selected text closes by itself.
- **Update tooltip**: the four new things under In this update now have a picture showing where they are.

**Updating**: a Mac with 0.9.5 or 0.9.6 finds this version by itself. For a new install, download the dmg and allow it once on first open, as described under Install above.

**Requirements**: macOS 14 or later on Apple silicon (M series); your own Claude Code or Codex subscription, or OpenCode. Homebrew is not needed.

**License**: GPL-3.0.
