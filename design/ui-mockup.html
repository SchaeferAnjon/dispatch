三个有意的决定

  1. Agent 是一等公民。每个 Agent 有身份色，卡片、表格、详情、活动流里都用同一枚头像；左栏 Agent 轨常驻，你一眼看到谁在哪个项目做哪条任务。
  2. 看板四列 = 你的四个状态。不另造一套；阻塞不占列，用红边条在"待办"里标出，因为它本质还是待办。
  3. 等宽字排 ID 和命令。task-9lo、bd update --claim 都是这块板的"母语"，活动流直接显示 Agent 敲了什么，审核时不用猜。
