# Agent 状态

> 这一页解决什么：哪个 Agent 在哪台机器上做什么。这里讲机器条、每个 Agent 的卡片、会话来源图标、编辑冲突提示、派活关系，以及从这里派活和看屏幕。

## 机器条

页面顶部一排是 `hosts.json` 里的每台 Mac：在线圆点、名字、IP、虚拟网类型（Tailscale、Netbird、ZeroTier）。每台后面的按钮按能力出现：

- **派活**：在这台机器的 Herdr 里起一个 Agent，可以把任务派给它（选 Agent、模型、目录、首条提示词）。
- **看它的屏幕并操作**（另一台开了屏幕共享时）：用系统「屏幕共享」打开。
- **复制手机看屏幕链接 ⧉**（那台配置了 noVNC 时）：发到手机上打开，手机需连着 Tailscale。
- **手机访问 ⧉**（本机）：复制 Dispatch 网页版链接。
- **看屏幕 ⧉**（本机配置了 noVNC）：复制这台的屏幕链接给手机或另一台电脑用，在本机打开会套娃。
- RustDesk、Moonlight、UU远程：检测到就给入口。

机器上右键：派活、复制 ssh 地址、复制 IP、看屏幕。空白处右键：在某台机器派活。

## Agent 卡片

每个在线或名下有任务的 Agent 一张卡：头像、名字、id、最近写入时间，状态标签（「N 个在跑」「N 空闲」「N 个只见进程、看不到会话」）。

- **来源行**：这个 Agent 的会话按来源分组计数：⌘ 终端、▣ 桌面端、◧ 编辑器、✉ 聊天、⏱ 定时，带脉冲点表示有在跑的。
- **会话列表**：活跃的（在跑或一小时内有动静）直接列出；更早的折在「更早的会话 · N」。每条：来源图标、标题、状态、来源应用或「实际会话记录」、机器、最近活动；「正在改：」列出最近 30 分钟改过的文件，**红色**表示多个会话在改同一个文件（`dispatch editing` 查得到）；下面是它关联的进行中任务。右侧「接到 Herdr」（在别的终端里跑时）和「打开」（切到会话所在的软件）。
- **关联进行中任务 · N**：它名下的任务，带「← 谁派的」。
- **派活关系**：派出 N（它派给别人的）、自派 N（派给自己另一个会话）、接到 N（别人派给它的）。

底部两个折叠：「定时会话 · N」（不计入在跑、未读和通知）和「未检测到活动的 Agent · N」。
