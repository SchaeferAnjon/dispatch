# 脉络

> 这一页解决什么：脉络页把一个项目的「任务 → 会话 → 进展 / 提交」画成一张图，回答「谁在哪个会话做哪个任务、做到哪」。这里讲图怎么读、怎么筛、清单视图是什么。

## 打开

侧栏「脉络」，左边选项目。命令行 `dispatch lineage [项目]` 输出的就是这份数据。默认看最近 14 天。

## 头部

项目名、「N 个任务 · N 个活会话 · N 个未挂会话」，下面一句话概括：「<谁> 在会话「…」做「…」」或「暂时没有进行中的任务」。切换「图 / 清单」，三个筛选：只看进行中、只看有活会话、只看我在等的。

## 图

节点分三种，从左到右：

- **任务**：标题、状态、负责人、验收进度、最后进展时间、提到次数。
- **会话**：Agent 头像和标题，状态（在跑 / 等你 / 已结束），关系（发起 / 在做 / 提到），「可关 / 别关」判断，「还涉及 N 个任务」。
- **进展 / 完成 / 提交**：进展原文首句、完成说明、提交信息，带日期。

连线：

| 线 | 含义 |
|:--|:--|
| 粗实线（发起会话） | 任务在这段会话里建的，主线 |
| 细虚线（顺带做） | 会话顺手接的其他任务 |
| 派生出 | `discovered-from` 依赖 |
| 解锁 | `blocks` 依赖 |
| 包含 | 父子任务 |
| 拆分自 | 讨论拆出的子任务 |

节点名就是任务标题、会话标题、进展原文首句，不缩写。悬停或选中一个节点整条线高亮，右栏看详情；点任务打开任务详情，点会话打开会话页。滑块缩放。「还没连上线的任务」和「未挂任务的会话」分别列在下面。

## 清单

同一份数据的树形列表：每个任务下面是它的会话（带关系、状态、判断）和事件（进展、完成、提交），按时间倒序。适合在手机上看。
