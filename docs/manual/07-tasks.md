# 全部任务与任务详情

> 这一页解决什么：任务板的全局视角。这里讲看板与表格怎么用、回收站与已归档、任务详情页的每一块（属性、验收、完成说明、留言、Git 提交、文件改动、相关的坑、讨论与分工）。

## 全部任务

侧栏「全部任务」进入。顶部工具栏：

- 视图切换：**看板**、**表格**、**回收站 N**、**已归档 N**。
- 筛选小标签：「Agent 复核 N」「阻塞 N」；搜索框；侧栏点某个项目或 Agent 后这里会显示「只看 <名字>」，点 ✕ 清除。
- 空白处右键：切到表格 / 看板、清除筛选、回收站、已归档任务、「归档 30 天前完成的（N）」，以及全局操作。

### 看板

四列：待办、进行中、阻塞、已完成。每列按项目分组，收藏的项目在前；分组可折叠，折叠状态每台设备记住；已完成列默认只显示最近 7 天，「还有 N 项更早完成的 ›」展开。列头「全部收起 / 全部展开」，待办列头的 ＋ 新建任务。排序：按优先级、按最近更新、按创建时间。

卡片上：标题、⋯ 菜单、「↑ 源自 <根任务>」（这条线的根）、优先级、项目、编号、类型、「A 派给 B」、「⊘ 被 N 项依赖卡住」、「⏸ 搁置」、验收进度条、「最近进展 / 进展备注 / 完成说明」或「下一验收项」、负责人和时间、「✓ 已复核」。

拖动卡片到另一列改状态：拖到待办是重新打开或改回待办，拖到进行中只改状态（不会把你设成负责人），拖到已完成会以「在 Dispatch 里拖到已完成」作为完成说明关闭。

### 表格

列：ID、任务、源自、状态、负责、优先、项目、依赖（← 依赖数 → 被依赖数）、更新、操作。点表头排序，再点反向，第三次恢复默认（收藏的项目在前）。

### 回收站与已归档

- **回收站**：移除的任务保留记录与依赖，不会进入待办队列。右键或 ⋯ 「从回收站恢复」恢复原状态。命令行 `dispatch task trash|restore <id>`。
- **已归档**：归档过的已完成任务，不进已完成列、不计数，记录和依赖都在。右键或 ⋯ 「取消归档」。设置里「已完成任务多少天后自动归档」可以自动做，也可以手动「归档 30 天前完成的」。

### 右键 / ⋯ 菜单

打开任务详情、在新窗口打开、复制任务 ID、复制任务内容、派给 Agent…（在某台机器的 Herdr 里起一个 Agent 认领它）、移到待办、移到进行中、标记完成、归档（已完成很久了）、移到回收站。

### 新建任务（⌘T）

标题（一句话说清要做什么）、描述（背景 + 要做什么 + 怎么算做完，写给下一个接手的 Agent 看）、类型、优先级、项目（已有项目、只是有过会话的目录、或新项目名）、验收标准（每行一条）。

## 任务详情

点任何任务打开右侧详情面板（手机上是整页）。<kbd>Esc</kbd> 关闭；⇥ 收起左栏让右栏的文件改动和产物占满宽度。

### 左栏

- **头部**：编号（悬停有说明）、项目、「编辑属性」（打开后可改标题、状态、优先级，能「标记完成」并填完成说明，或「重新打开」）。
- **属性**：状态、负责、优先级、派活（谁派给谁）、类型、项目、源自（根任务）、标签、依赖、被依赖、创建时间和创建者、完成时间。
- **讨论与分工**（未完成的任务，或有过讨论 / 子任务时）：讨论结论、每条【讨论】发言、子任务列表；「发起讨论…」让选中的 Agent 无头直调各留一条【讨论】评论（通常一分钟内到齐），「拆分并派活…」按你填的行建子任务并在 Herdr 里起对应 Agent。
- **交付与验证**（已完成）：「N/N 项已勾选 · N 项仍待核对」、待核对的验收项、记录依据（最近三条进展、关联会话）。标题右侧写着状态：「已完成 · 无需你点击审核」「等待 Agent 复核」或「已记录复核通过」。缺完成说明时会提示。
- **完成说明**：`done --reason` 的内容，可展开。
- **描述**：Markdown，双击编辑；空的时候提示「还没写描述，下一个接手的 Agent 会不知道为什么做这件事」。
- **验收标准**：`- [ ]` 清单，点勾选框勾上或取消，署名「你核对」；Agent 勾的显示「自审 · <Agent>」或「复核 · <Agent>」；旧记录可能「未署名」。「编辑」直接改文本。
- **活动**：状态变化、认领、留言，每条带作者和时间。
- **留言框**：「留言给下一个接手的 Agent…」，<kbd>⌘⏎</kbd> 发送。Agent 下次开会话时，`dispatch prime` 会把它名下任务上未回复的留言注入给它。

### 右栏

- **相关的坑**：按这条任务的意思在知识库里找到的坑（有语义搜索时跨项目，带相似度；否则本项目的），显示现象和解法。
- **Git 提交**：提交信息末尾带这个任务 id，或完成说明里写了哈希的提交，每条有短哈希、标题、+N −M、时间；展开看文件列表，「在 GitHub 打开 ↗」「复制哈希」。空的时候说明为什么（还没有对上的提交，或项目不在 git 仓库里）。
- **文件修改与产出**：明确关联的会话里记录到的文件改动（每处 diff）和产物（图片网格、文件按钮）。没有关联会话时提示：Agent 认领或记进展时会自动关联。
- **对话中提到过**：转录里提到这个任务 id 的会话，仅供参考，不代表归属；每条可「查看记录」「复制恢复命令」。
