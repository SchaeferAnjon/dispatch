# 工作台

> 这一页解决什么：工作台是打开 Dispatch 看到的第一页，回答「每个项目此刻什么情况」。这里讲每一行、每个按钮的含义，以及怎么把它调成你顺手的样子。

![工作台](../assets/shot-home.png)

## 页面结构

从上到下：

1. **标题行**：「工作台」和「N 项未完成」；下面一行小字是连接状态：「每 3 秒同步会话活动」，中断时显示「更新中断 · 正在重连」，另一台电脑连不上时会写「<机器> 暂时连不上」。右边两个按钮：「讨论一个念头」（见 [总览与讨论](15-overview.md)）和「新建会话」。
2. **计数条**：四个可点的计数，点一下只看对应的项目，再点取消：
   - **未读回复**：Agent 答完等你看的会话。
   - **等待确认**：停在确认框的会话。
   - **被卡住**：有未完成依赖的任务。
   - **在跑**：正在工作的会话。
   右边是「全部展开 / 全部收起」、项目排序（按最近活动、按会话数、按未完成任务、按名称；收藏的总在最前）、「手机访问 ⧉」（复制手机链接）、「看屏幕 ⧉」（配置过屏幕访问才可点）。
3. **洞察行**（有的话）：最近 14 天跨 Agent 复盘的一句话，带「N 条新」告警计数；点它进统计页的洞察部分。
4. **追踪中**：你收藏的会话，跨项目集中在这里，最多显示 6 条。
5. **项目卡片**：每个项目一张。
6. **其他项目**：三天内没动静的项目折成一行一个，点「展开 N 个」。
7. **已归档**：归档过的项目，可「取消归档」。

## 一张项目卡片

卡片头：折叠箭头、项目色块、项目名（点进项目页）、☆ 收藏、计数（「N 个会话 · N 项未完成 · N 项被卡住 · N 项成果」）、「新建会话」、「进入项目 ›」。折叠时头部变成几个摘要小标签：「等你 N」「在跑 N」「追踪 N」「任务 N」「卡住 N」，点「等你」跳到项目页的会话标签，点「任务」跳到项目回顾。

展开后按顺序显示这些分组（没有内容的分组不显示，每组最多 3 条，多的用底部「还有 N 项，进入项目 ›」）：

| 分组 | 内容 | 点击 |
|:--|:--|:--|
| 等你 | 等待确认的会话（状态标签写着它在等什么）和未读回复（标签「未读回复」，下面一行是这轮回复摘要） | 「查看并回复」打开会话页 |
| 在跑 | 正在工作的会话，「正在做：…」是它当前的动作 | 打开会话页 |
| 追踪中 | 收藏的会话（不在上面两组里的） | 打开会话页 |
| 被卡住 | 状态为阻塞的任务，「依赖 N 项未完成」，等依赖完成会自动解开 | 打开任务详情 |
| 进行中的任务 | 负责人头像、优先级、标题，下面一行是「最新：<进展>」或「下一项：<验收项>」，右边是验收进度条 | 打开任务详情 |
| 最近一次会话 | 项目没有任何活动时显示最后一段会话 | 打开会话页 |

卡片底部：「最新成果 · <标题> ›」（没有则「还没登记成果」）。

哪些卡片默认展开：设置里「默认展开前几个项目」（默认 2）之内的，以及有「等你」内容的。你手动折叠或展开后，以你的操作为准。

## 右键

- 项目名或卡片上右键：进入项目、在新窗口打开、在这个项目新建会话、只看它的任务、收藏 / 取消收藏、归档 / 取消归档。
- 会话行上右键：查看并回复、在新窗口打开、在终端里打开会话、标记已读 / 标为未读、收藏（长期追踪）、归档、标记为定时会话、改名、关联项目、用模型总结这段会话、复制恢复命令、迁移到另一台。
- 任务行上右键：打开任务详情、在新窗口打开、复制任务 ID、复制任务内容、派给 Agent、移到待办 / 进行中、标记完成、移到回收站。
- 空白处右键：本页操作（全部展开 / 收起）加上全局操作（新建会话 ⌘N、新建任务 ⌘T、刷新 ⌘R、搜索 ⌘K、复制手机访问链接）。

<kbd>⌘</kbd>+点击任何代表项目、会话或任务的东西，都会在新窗口打开它。

## 顶部栏与侧栏

- 顶部左侧是面包屑：当前页面名，进入项目或会话后有「‹ 返回工作台」之类的按钮，退回上一页。
- 顶部右侧：「搜索 ⌘K」、各 Agent 的额度条（本机的用量，悬停看重置时间）、「＋ 会话」、主题切换、⧉「分离」（把当前页面挪到独立窗口，这里回到上一页）。
- 左侧栏：工作台、项目、等我（红色角标是未读回复 + 等待确认 + 只能你做的数量）、会话、讨论；任务组（全部任务、脉络）；Agent 组（Agent 状态、统计与额度，下面列在线的 Agent 和它们名下的任务）；知识组（技能、规则与资料、知识库、设置、总览）。有两台机器时侧栏顶部多一排「全部 / 机器名」的筛选。
- 菜单栏图标：显示「未读数 ●● 在跑数」，点开看等你、待复核、未完成计数和各 Agent 额度。

## 没有项目时

「还没有项目。会话按工作目录归入项目，任务用 `project:名字` 标签归类。」先在终端开一段会话，或者点「新建会话 ›」。如果会话明明在跑却没出现，检查 设置 → 项目 → 工作区根目录，以及 [排错](24-troubleshooting.md#读不到会话)。
