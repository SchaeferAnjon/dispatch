# 项目页

> 这一页解决什么：项目页是一个项目的全部记录。这里讲项目列表怎么看，以及进入一个项目后八个标签（项目回顾、会话、任务、成果、待归属任务、目录、文档、知识库）各放什么、能做什么。

![项目页](../assets/shot-project.png)

## 项目列表

从侧栏「项目」进入。上面是搜索框和排序（最近活动、名称、会话数、待完成任务、所属电脑）。有动静的项目是卡片：显示名、☆、所属电脑（「项目目录目前在这台电脑上」或「项目已交接给这台」）、未读数、一行摘要（「进行中 · <任务>」「最新成果 · <标题>」或「最近会话 · <标题>」）、「N 个会话 · N 个待完成任务 · N 项成果」。一周没动静的折到「最近没有动静 · N」。

底部两个按钮：「其他目录与未归类 · N」（只有会话、没有任务和成果的目录）和「已归档 · N」。右键项目卡片有收藏、归档、新建会话等操作。

## 项目头部

- **标题**：双击改显示名（标签和目录不变，改的只是显示；留空恢复）。旁边是 ☆ 收藏、所属电脑徽章、「已归档」标记。
- 下面一行是项目目录和「N 个会话 · N 个任务 · N 项成果」。正在迁移时这里有进度条。
- 按钮：
  - **终端 · <机器> ▾**：在项目目录打开一个终端标签，菜单里选 Claude Code、Codex 等 Agent（会起对应 Agent），或「普通终端」（不带 Agent）。
  - **讨论…**：就这个项目的一个想法让几个 Agent 各说一次并出结论。
  - **迁移到 <机器>**（有第二台时）：把项目目录、Git 和这边在跑的会话交给那台，先预检再动手，见 [两台电脑](21-two-macs.md)。
  - **在此项目新建会话**。
  - **归档 / 取消归档**。

## 标签页

### 项目回顾

`dispatch here <项目>` 画出来的页面，四块：

1. **现状**：用设置里选的总结模型写的一段话（第一次可能要等半分钟，有缓存，超过一天自动重写）。总结关闭或没有模型时显示原因。
2. **最近 14 天**：时间线。可切 3 / 7 / 14 天，「放大」去掉高度限制整页滚动；「按任务」分组（同一任务的进展、完成、提交、会话放一起，未挂任务的单独一组）或「按时间」（按天分组，最新一天默认展开，每天默认 4 条）。每条前面是类型标签：进展、完成、提交（带 7 位哈希）、会话；点会话或任务条目直接打开。
3. **还没做完**：未完成任务，带「N/N 验收」、负责人、最后进展时间和最后一条进展。
4. **本目录活会话**：这个目录下正在运行的每段会话，标题、Agent、状态（在跑 / 等你 / 未登记）、动过几个文件、一段总结，以及一个判断：「可关」（点两次确认，关掉它的 Herdr 标签和进程）或「别关」（点开看看为什么）。「恢复」在 Herdr 里重新打开这段会话。

### 会话

这个项目的会话列表，收藏的在前。搜索框搜标题、目录和总结；「已归档 N」切到归档的（手动归档或超过设置天数没活动的）；「定时会话 N」切到定时或脚本起的。每一行：本机 / 机器名、★、标题、状态标签、「未读这轮」摘要或模型总结、「你说过的」（你在这段会话里提过的要求）、最新回复或进展、「正在做」、Agent、文件改动数、时间。行下面是它关联的任务和「可关 / 别关」判断。右侧按钮：「已读」、「查看并回复」、「✦ 总结 / 重新总结」（会调模型）、「更多」（右键菜单）。

### 任务

四列看板：**只能你做**、待办、进行中、已完成（最近 7 天，「全部 N ›」进入按周分组、可搜索的完整列表）。

- 「只能你做」列放 Agent 用 `dispatch need-you` 记的事，前面有勾选框，做完打勾就关闭。空的时候提示：Agent 遇到只有你能做的事（发邮件、付款、登录、演示）会记在这里。
- 其他列每条显示标题、状态和它的发起 / 参与会话；「指定是哪次会话」可以手动选发起会话和参与会话。

### 成果

「登记成果」打开表单：成果名称、交付内容与查看入口（Markdown，可以贴文档、截图、版本或代码链接）、来源任务（可多选）、补充来源会话（已选任务的会话会一并关联）。保存后成果卡片显示正文和它关联的任务、会话；「编辑」可改。底部「历史完成记录 · N 项」列出所有已完成任务的完成说明，它们还没整理成独立成果。

### 待归属任务

没有明确关联会话的任务。Dispatch 不根据提及次数猜测归属，你可以在这里「指定是哪次会话」。

### 目录

这个项目的会话在哪些文件夹里发生过，每个文件夹有会话数、最近时间，以及「在此目录新建会话」「在 Finder 打开」「复制 cd」。

### 文档

上半部分是**常用信息**：项目目录里的 `FACTS.md`，放只属于这个项目的短事实（服务器入口、登录方式、找谁）。Agent 不会每次注入，需要时才 `dispatch facts get -P <项目> <主题>` 读。没有就「建一份」（带模板），有就「编辑」；保存后记得 commit。下面列出登记到这个项目的密钥名和用途（值在「规则与资料 → 密钥与 API」），带「复制取用命令」。

下半部分是**文档列表**：扫描项目的 `design/`、`docs/`、`研究/` 目录下的 `.md` 和 `.html`，加上你登记的路径或 URL（`dispatch docs add`）。类型有调研、复审、设计、文档、其他。Markdown 在应用里直接读（相对路径的图片也能显示），HTML 用默认应用打开，URL 打开链接。在另一台电脑上的文档会标机器名，暂时只能读 Markdown。

### 知识库

知识库里带这个项目名的条目：坑、做对、复盘、做法，可按类型筛选和搜索。空的时候提示 Agent 用 `dispatch wiki add --kind pit/win -P <项目>` 记。全局视图见 [知识库](13-wiki.md)。
