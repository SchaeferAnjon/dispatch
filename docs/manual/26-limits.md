# 已知限制

> 这一页解决什么：如实列出当前版本（v0.7.34）还存在的限制。2026-09-17 的全源码审读指出的问题已在 v0.7.29 到 v0.7.34 之间逐条修掉，修了什么列在页尾；这里只留仍然成立的。会随版本更新。

## 安装与分发

- **只有 Apple 芯片的包。** Release 里只有 `macos-apple-silicon.zip`；Intel 机器需要从源码构建（`cd app && npm ci && npm run tauri build`，需要 Node.js、Rust、Xcode Command Line Tools）。应用内更新器在 Intel 机器上会明确提示没有对应包，不会装错架构的包。
- **没有 Apple 公证。** 第一次打开会被 Gatekeeper 拦下，按 [五分钟上手](01-quickstart.md) 里的办法放行一次。
- **需要 Python 3.9 或更新。** 装了 Xcode 命令行工具或 Homebrew 的 Mac 都有；都没有时应用会显示「环境检查」页，列出缺什么、怎么装。

## 功能范围

- **技能挂载只支持 Claude Code 和 Codex。** pi、ZCode、Gemini CLI、OpenCode 能看会话和任务，但技能池不会挂到它们下面。
- **回复原会话**：Herdr 里的会话功能最全（排队、打断、撤回、按键）。直接开在 Ghostty 里的会话能排队和打断；开在 Terminal.app / iTerm2 里的只能排队，不能打断（iTerm2 这条路径按它的脚本接口实现，作者机器上没有 iTerm2，未实测）；VS Code 扩展里的会话要先「接进 Herdr」。
- **模型下拉里的模型名写在界面里**（回复框、派活、讨论），新模型要等应用更新才会出现；填自定义模型名不受影响。
- **读取索引上限**：本机会话列表 500 条、远端 200 条；历史条目不显示未读或推断运行状态。
- **工作区 Git 差异**可能包含其他会话的改动。
- **附件**：只能读当前会话明确附加或链接的文件，图片单个 20 MB、其它文件 50 MB；依赖外部库的 HTML 产物需要在原项目里运行。
- **「潜在冲突」是静态检查**，不是完整语义证明。
- 不接入 ChatGPT 网页会话；拿不到原 Agent 应用的「已读」回执。

## 两台电脑

- **枢纽的同步端口（3309）监听所有网卡。** Dolt 的 remotesapi 不能指定监听地址，靠同步用户的密码保护；不要把这个端口映射到公网。
- **两台电脑之间的同步不加密。** 走 Tailscale 时由 Tailscale 加密；选了「同一 Wi‑Fi」时任务内容和同步密码在局域网里是明文，只在自己家里或信得过的网络用，公共 Wi‑Fi、宿舍网和公司网请用 Tailscale。手机网页（7799 端口）同理，是 HTTP。
- 两台电脑版本不一致时，较旧的一台保存设置会丢掉它不认识的新设置项（例如手机通知开关）。两台一起更新就没有这个问题。

## 手机

- 配对用的二维码和链接带的是长期有效的令牌（保存在 `~/tasks/.dispatch/serve.json`，扫一次后手机用 cookie 记住）：只在设置页显示，别发到公开的地方。通知里的链接用的是单次有效的登录码：走 Bark 时 24 小时内有效，走 ntfy 时 15 分钟内有效（ntfy 的主题名被人猜到就能读到通知）。
- 没有 Tailscale 时默认只监听本机；勾了「允许局域网」后，同一 Wi‑Fi 的设备都能访问端口 7799（仍需令牌）。公共 Wi‑Fi 上建议关掉。
- 网页版弹不出系统通知，推送要靠 Bark 或 ntfy。

## v0.7.29 到 v0.7.34 修掉的（供对照旧版说明）

- CLI 兼容系统自带的 Python 3.9；应用自己探测解释器，环境不全时显示自检页；缺 bd / git / herdr 或没建任务板时给一行提示，不再是 traceback。
- 模型调用改成你选了才开：首次设置的「模型与总结」里选关闭、Claude Code 订阅或 API Key，并勾选具体用途；默认什么都不发。DeepSeek 不再被内置停用，改成设置项。
- 手机访问在设置页一键开启（常驻服务随应用分发）；没有地址可达时不再画二维码；日志不含令牌且只有本人可读。
- 首次设置不再覆盖你的 Claude Code 状态行（会保留并转发），改动前备份 settings.json；hook 用绝对路径；编辑互斥改成可选、默认不装；署名默认用本机用户名。
- 新建会话、派活、讨论默认选你装了的 Agent，没装的置灰；额度页只列已装的；洞察报告用你选的总结模型。
- 防休眠改成这台电脑自己的设置，默认只防系统休眠；支持 Terminal.app / iTerm2；技能池位置自适应（有 cc-switch 用它的目录，否则 `~/.agents/skill-pool`）；远端命令用对端自己的任务板目录；局域网接入迁移后也会标记「已搬走」。
- 更新器能装在任何位置、接口限流时走公开下载地址、安装前校验 SHA256；所有 ssh、子进程、手机请求都有超时；应用单实例、有内容安全策略、字体随包、不再往 .app 里写 `__pycache__`。
- 性能：`prime` 更快；工作台只在任务变化时拉评论；洞察按会话缓存。
- `dispatch env` 同时生成 zsh / bash 用的 `env.sh`，密钥文件原子写入。
