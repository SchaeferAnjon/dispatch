# 总览与讨论

> 这一页解决什么：两个不太一样的页面。「总览」是应用自带的地图，每个页面一句话；「讨论」是让几个 Agent 就一个念头各说一次、出结论、再派人去做。

## 总览

侧栏最下面的「总览」，或点左上角 Logo。一句话概括产品：一条线贯穿所有页面：项目里发生会话，会话延伸出任务，任务汇成成果。Agent 在下面干活，你在上面看、回复、派活。

- 每个页面一张卡，一句话说它干什么，带实时数字（在跑的会话数、未完成任务数、项目数、等你的数量、技能数、知识库条数、规则是否同步、版本），点卡进去。
- 「看一遍导览」：五步弹窗，每步切到对应页面。
- 「首次设置」：重开向导。
- 「怎么用」五条：右键、快捷键、手机、两台电脑、Agent 怎么知道任务板。

## 讨论

侧栏「讨论」，或工作台 / 项目页的「讨论一个念头」「讨论…」。

**是什么**：把一个念头交给几个 Agent（Claude、Codex、pi 等，可指定模型和领队），它们无头直调（`claude -p`、`codex exec`、`pi -p`）各留一条【讨论】评论，领队每轮最后发言并归纳；最后由总结模型写【结论】，还能整理成文档（背景 / 结论 / 方案 / 步骤 / 风险 / 验收），然后「派 Agent 去做」或「拆分」成子任务。每个念头在任务板上是一条【讨论】任务。

**页面**：左边是讨论列表（搜索、含已归档），右边是选中的讨论：念头（可带图片）、参加者（领队有标记）、发言流、结论、文档，按钮：再来一轮、整理成文档、派 Agent 去做 →、拆分、归档。「摘要」折叠头部信息。

**讨论现场与顺便问**：发言流上方是「讨论现场」，每个参加者一个小人围坐，谁在想、谁在说、谁没说上话一眼可见。讨论列表和摘要两栏可以各自收起成窄条；聊天栏够宽时聊天在左、现场在右并放大。现场角落里坐着一位「同学」：看讨论时哪个词、哪句话没听懂，点他直接问，或者在讨论里划一句话点「问同学」。他读着这场讨论的上下文，用大白话加一个小例子讲给你。问答存在讨论旁边，不写进任务，参加者看不到，不影响讨论本身。用的是总结模型（没配就用领队的模型），受 设置 → 总结 里「讨论结论」这个开关控制。

**成本提醒**：每个参与者都是一整个新会话的 token。Agent 自己不会主动发起讨论，只有你在界面或命令行里明确要求才会。人设和规矩在 [设置 → 讨论](14-settings.md#讨论)。

命令行：`dispatch discuss --topic "念头" -P 项目 --with claude:opus,codex --leader pi --rounds 2 --conclude`，`dispatch discuss-doc <id>`，`dispatch split <id> --to codex:"子任务|说明"`。
