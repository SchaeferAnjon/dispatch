# 术语表与快捷键

> 这一页解决什么：界面和命令里出现的词，一句话解释；桌面版的快捷键和鼠标操作。

## 术语表

| 术语 | 含义 |
|:--|:--|
| Agent | 编程助手：Claude Code、Codex、pi、ZCode、Gemini CLI、OpenCode、Hermes。Dispatch 只读它们的记录，不代替它们 |
| 会话 | 一个 Agent 在一个目录里的一次完整对话，来自它自己的转录文件或数据库 |
| 项目 | 会话按工作目录归属的单位；有任务、成果或手动关联的才是正式项目，其余是「目录」 |
| 工作区根目录 | 设置里的文件夹列表（默认 `~/Projects`），其直接子文件夹各算一个项目 |
| 任务 | 中央任务板（Beads）上的一条记录，由 Agent 用 `dispatch begin/log/done` 记 |
| 任务板 | Beads 数据库，目录 `~/tasks/.beads`，Dolt 存储，两台电脑同步 |
| Beads / bd | 任务板软件和它的命令行 |
| Dolt | 带版本历史的数据库，任务板用它存储和同步 |
| Herdr | 终端里的 Agent 多路复用器，靠 tmux 常驻；派活、回复原会话、判断状态都经过它 |
| 枢纽 | 第一台完成首次设置的 Mac，任务板、规则、技能都在它上面 |
| 接入 | 第二台 Mac 使用枢纽的任务板 |
| 迁移 | 把项目或会话搬到另一台 Mac 接着做 |
| 成果 | 独立的交付记录（`dispatch:outcome`），可关联多个任务和会话 |
| 验收标准 | 任务里的 `- [ ]` 清单，勾选会署名 |
| 完成说明 | `dispatch done --reason` 写的交付与验证 |
| 等我 | 需要你处理的：未读回复、等待确认、只能你做 |
| 未读回复 | Agent 答完、你还没读到最新一轮 |
| 等待确认 | Agent 停在权限、信任目录等确认框上 |
| 只能你做 | Agent 用 `dispatch need-you` 记的、只有你能做的事 |
| 被卡住 / 阻塞 | 有未完成依赖的任务，依赖完成自动解开 |
| 搁置 | 暂不安排的任务状态 |
| Agent 复核 | 一个 Agent 请求另一个 Agent 独立复核（`--review-by` / `dispatch review`） |
| 追踪中 | 收藏的会话或项目，置顶，不自动归档 |
| 归档 | 从工作台和列表隐藏，随时找回；会话超过设定天数没活动会自动归档 |
| 回收站 | 移除的任务，保留记录与依赖，可恢复 |
| 定时会话 | 定时任务、脚本或别的 Agent 通过程序接口起的会话，不进等我、不发通知 |
| 零散会话 | 没有标题、最多一句话的会话，折叠在会话列表底部 |
| 来源 | 会话从哪里开的：终端、桌面端、VS Code、SDK、定时任务、Telegram 等 |
| 接进 Herdr | `dispatch adopt`：停掉别的终端里空闲的会话进程，在 Herdr 里 `--resume` 同一段 |
| 恢复 | 原终端关了之后在 Herdr 里重新打开同一份记录 |
| 排队发送 / 打断并发送 | Agent 在跑时把消息排到本轮之后，或先 Esc 再发 |
| 撤回 | 从 Claude Code 的队列里拿回还没处理的消息 |
| 分屏 / 分离 | 一页里并排 2 或 4 段会话；把当前页面挪到独立窗口 |
| 知识库 / wiki | 所有 Agent 共用的经验：坑、做对、复盘、做法，存在 Beads memory |
| 坑 / 做对 / 复盘 / 做法 | 知识库的四种条目 |
| 规则 / GLOBAL.md | 所有 Agent 的共同规则，唯一来源 `~/.agents/rules/GLOBAL.md` |
| 托管块 | 同步进各 Agent 入口文件里的那段 GLOBAL.md 内容 |
| 常用资料 / FACTS.md | 服务器、数据库、账号用途；全局 `~/.agents/rules/FACTS.md`，项目的在项目目录 |
| 密钥 / dispatch env | `~/.config/dispatch/env` 里的 API Key 和密码，Agent 只看到名字 |
| 记忆 | 各 Agent 自己跨会话积累的长期记忆文件 |
| 关于我 / PROFILE.md | 关于用户本人的档案，Agent 自动维护 |
| 技能池 | `~/.cc-switch/skills`，每个技能一个带 SKILL.md 的目录 |
| 挂载 | 把技能软链到某个 Agent 的技能目录 |
| prime | `dispatch prime`：会话启动时注入的摘要 |
| hook | Claude Code 的事件钩子，用来上报状态、注入 prime、编辑互斥 |
| 脉络 | 任务 → 会话 → 进展 / 提交的图 |
| 洞察 | 跨 Agent 的复盘信号和模型写的报告 |
| 讨论 | 几个 Agent 就一个念头各说一次、出结论 |
| 派活 | 在某台机器的 Herdr 里起一个 Agent 做某个任务 |
| 额度 | 各 Agent 订阅的用量窗口和重置时间 |
| 总结模型 | 设置里选的、用来写会话总结、项目现状等的模型 |
| Tailscale | 虚拟私网，手机和第二台电脑靠它访问 |
| ntfy / Bark | 手机推送渠道 |
| noVNC | 手机浏览器里看并操作电脑屏幕 |
| 机器 / hosts.json | `~/tasks/.dispatch/hosts.json` 里登记的每台 Mac |

## 快捷键（桌面版）

| 按键 | 作用 |
|:--|:--|
| <kbd>⌘K</kbd> | 搜索项目、会话、任务 |
| <kbd>⌘N</kbd> | 新建会话 |
| <kbd>⌘T</kbd> | 新建任务 |
| <kbd>⌘R</kbd> | 刷新 |
| <kbd>⌘⏎</kbd> | 发送回复、发送留言、保存对话框（新任务、记一条、密钥、技能） |
| <kbd>⌘S</kbd> | 保存正在编辑的 SKILL.md |
| <kbd>Esc</kbd> | 关闭对话框、关闭任务详情（编辑属性时先退出编辑）、关掉 / 命令菜单、清空搜索框 |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>⏎</kbd> | 搜索面板、/ 命令菜单和右键菜单里移动、选择 |
| <kbd>→</kbd> <kbd>←</kbd> | 导览里下一步 / 上一步 |
| <kbd>⌘</kbd>+点击 | 项目、会话、任务在新窗口打开 |
| 右键 | 任务、会话、项目、技能、文件、机器、知识库条目、规则文档各自的菜单；空白处是本页操作。手机上长按约半秒 |
| 双击 | 项目标题改显示名；任务描述进入编辑 |
| 拖动 | 看板卡片换列 |

快捷键在输入框里也会触发（已知限制）。
