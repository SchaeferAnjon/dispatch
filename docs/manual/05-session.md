# 会话页

> 这一页解决什么：会话页是看 Agent 每一步和直接回复的地方。这里讲列表怎么筛、会话详情的每个标签、回复框的每个按钮（排队、打断、撤回、恢复、接进 Herdr、确认框按键），以及分屏、分离窗口和返回。

![会话](../assets/shot-session.png)

## 左侧：会话列表

- 搜索框：标题、目录、任务 ID、会话 ID 前缀。
- 四个模式：**最近**（默认）、**★ 追踪中**（收藏的，长期追踪，不自动归档）、**已归档**（手动归档或超过设置天数没活动）、**定时或脚本**（定时任务、脚本或别的 Agent 通过程序接口起的；有才显示）。
- 按 Agent 筛选：全部、Claude Code、Codex、pi、ZCode、OpenCode、Hermes。右边是当前筛选下的条数。
- 每一行：头像、★、标题（在跑的绿色高亮；答完等你看的有蓝点；没在 Dispatch 索引里但进程还在的标「在跑 / 开着」）、项目色块和项目名、本机 / 机器名、「已迁往 / 从 … 迁来」、来源（终端、桌面端、VS Code、SDK 等）、「N 轮」对话、子 Agent 数、时间；下面一行是它当前的动作或最新进展，再下面是关联的未完成任务。
- 没有标题、最多一句话的零散会话折到底部「零散会话」。
- 第一次打开要读完全部历史，显示「索引中…」；之后看过的会话再打开秒显，再拉新增部分。

点「⇤ 收起列表」让对话占满整页（每台设备记住）。

## 右侧：一段会话

### 头部

「‹ 会话」或「‹ 返回<上一页>」、头像、本机 / 机器名、标题、`目录 · 分支 · 会话 ID`；右边：「项目 · <名> ›」回到项目页、「⊞ 分屏」、「接到 Herdr」（会话在别的终端里时）、「打开 <Agent> 会话 ↗」（在那台电脑的原 Agent 里打开或恢复它）、「复制恢复命令」（去终端粘贴回车就能续上）、⋯ 菜单。

头部下面：

- **总结**（有的话）：模型写的一段话，目标、做了什么、还差什么；手机上默认折成一行，点开。
- **实时状态行**：绿色圆点表示在跑；文字是当前状态（「正在调用 Bash…」「正在回复…」「思考中…」）和最近活动时间；连接中断时显示「更新中断，保留上次记录」。
- **会话信息**（折叠）：开始时间、最近时间、来源、轮数与回复数与大小、工具调用统计、子 Agent 列表。

### 标签

| 标签 | 内容 |
|:--|:--|
| 对话 | 时间线。你的消息、Agent 的思考（折叠，点开看全文）、工具调用卡片（名字、关键参数、状态 ✓ ✗ …，点开看全部参数和输出；编辑类工具显示成 `Update(路径) +N −M` 的 diff，小改动默认展开）、连续的工具调用折成一行「跑了 N 条命令 ›」、图片内联、系统事件（子 Agent 完成、hook 通知）。在跑时每 1.5 秒拉新增部分并自动跟到底；你往上翻就停止跟随，右下角出现「回到最新 ↓」。右上角两个开关：「只看结论」（只显示你的问题和每轮最后的回复）、「工具调用」（显示或隐藏工具卡片，正在运行的总会显示）。 |
| 图片与产物 | 这段会话里附加或生成的图片、PDF、HTML、音视频、文本，集中预览。HTML 在隔离的 iframe 里预览，外部网络禁用。单个文件上限 20 MB。 |
| 文件 | 「这段会话改过的文件」：从编辑类工具调用里记录的每处改动，按文件折叠，显示 diff。用终端命令改的文件不在这里；下面「目录里现在的 git 改动」折叠区显示整个工作区的未提交差异（同目录所有会话的改动，不只这一段），每个文件可展开补丁，超过 100 KB 截断。文件上右键可打开、在访达中打开、复制路径。 |
| 任务与成果 | 这段会话明确关联的任务（发起 / 参与）和成果；「对话中还提及过 N 个任务」只是线索，不代表归属。 |
| 子 Agent | 这段会话派出的子 Agent，每个是一段独立对话，点开看它的完整记录和改的文件；「派发调用」列出派它们的工具调用。 |

### 回复框

底部永远是回复框，状态行写着连接情况：

- 「正在连接原会话…」→ 连上后显示原会话在哪里（Herdr 标签、Codex 桌面端等）。
- 连上且是 Claude Code 时，可以切**权限模式**（手动确认、自动接受编辑、计划模式、跳过权限；等于终端里的 Shift+Tab）和**模型**（等于 `/model`，在跑时不能切）。

输入：

- 直接打字；<kbd>⌘⏎</kbd> 发送；⤢ 放大输入框。草稿按会话保存。
- 输入 `/` 弹出可用命令菜单（内置命令、技能、自定义命令），↑↓ 选，⏎ 或 Tab 填入。
- 📷 发图片：手机可拍照或选相册，电脑可直接粘贴。图片存到会话所在的电脑上，Claude Code 收到的是附件，其他 Agent 收到的是路径。大图会缩到 2000 像素以内。
- 发送按钮的文字随状态变：**发送**（空闲）、**排队发送**（在跑：排进队列，本轮结束 Agent 就会看到）、**确认发送结果**（上一次发送没收到回执）。
- **打断并发送**（在跑时出现）：先按 Esc 打断当前这轮，再把这条发给它。

发出去之后：

- 被接受的消息在框上方显示「你 · <备注>」和正文；多条时写「已排队 N 条，本轮结束后按顺序处理」。消息进入对话后这一行消失。
- Claude Code 且还在队列里的最后一条可以**撤回**（拿回来不发了）或**撤回并编辑**（放回输入框改好再发）。
- 送达不确定时显示「检查送达状态」和「已核对，继续编辑」；重复点发送不会发两条，同一条消息只发一次。

原会话没在跑或不在 Herdr 里时，状态行给出对应按钮：

- **接进 Herdr 再发**：会话在 Warp、iTerm、Terminal 或 VS Code 扩展里。停掉那边空闲的进程，在那台电脑的 Herdr 里 `--resume` 同一段对话，再发这条。VS Code 扩展里的会话接过来之后，要回 VS Code 得重新 resume。它正在跑时按钮不可点，等它停下来。
- **在电脑上恢复并发送 / 在电脑上恢复这段会话**：原终端已经关了。在电脑的 Herdr 里新开一个页签恢复同一份记录，恢复好把你打的这条发过去。手机上一键完成。
- **重新连接**：再查一次。

Agent 停在确认框时（信任目录、权限、hook 审查等）：

- Claude Code / pi / Codex 终端会话：回复框上方显示「它在电脑上等确认」和那块屏幕的最后 14 行，下面一排按键 ↑ ↓ ⏎ Esc y n 1 2 3 直接发到原终端。
- Codex 桌面端：显示它在等什么（要跑命令、要改文件、申请权限、在提问、要你选），可以「批准」「本会话都批准」「拒绝」，问题可以选项或自己写后「回答」；「要你选」和 MCP 请求得在桌面端里处理。它在跑时有「打断」。

回复的边界：只投递给所选电脑上的原会话；Herdr 终端必须同时匹配会话 ID 与前台进程；正在执行或等待权限确认时不会写入输入。发送回执存在本机 `~/tasks/.dispatch/reply-receipts.sqlite`，不跨机复制。

## 分屏、分离窗口、新窗口

![分屏](../assets/shot-split.png)

- **⊞ 分屏**：当前会话放左边，再从列表点一段放进高亮的格子；「2 格」「4 格」切换；每格是独立的会话页（各自的记录、回复框和轮询），✕ 关掉一格，「退出分屏」回到单页。
- **⧉ 分离**（顶部栏）：把当前页面挪到一个独立窗口，原窗口回到上一页或所属项目。
- **右键 → 在新窗口打开**，或 <kbd>⌘</kbd>+点击项目、会话、任务：直接开新窗口。
- **返回**：顶部「‹ 返回<上一页>」按钮，或会话头部的「‹ 会话」。从工作台点进来的回工作台，从项目点进来的回项目，滚动位置会记住。

## 右键菜单（会话）

查看并回复、在新窗口打开、在终端里打开会话、标记已读 / 标为未读（回到「等我」里稍后再看）、收藏：长期追踪 / 取消收藏、归档 / 取消归档（转为追踪中）、标记为定时会话 / 恢复为普通会话、改名…（只改 Dispatch 里显示的名字）、关联项目…（关联后显示此项目名，不移动工作文件夹）、用模型总结这段会话 / 重新总结、复制恢复命令、派活、迁移到 <机器> 接着做。不方便右键时点行尾的「更多」。

## 新建会话（⌘N）

选运行电脑（离线的不可选）、Agent（能在 Dispatch 里看到对话并回复的：Claude Code、Codex、pi、OpenCode、Hermes）、工作文件夹（输入路径、从 Finder 选、或在下面浏览，有最近使用列表）、第一条消息（可粘贴图片，📷 加图片、📎 加文件，都存到运行那台电脑上，Agent 用 Read 看）。「创建并发送」后 Agent 在所选电脑的 Herdr 里起来，沿用已有登录和权限设置；本机会切到 Herdr 所在的终端，也可以留在 Dispatch 看进展。
